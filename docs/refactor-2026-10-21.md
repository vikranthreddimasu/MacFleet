# MacFleet refactor verification — October 21, 2026

This pass simplifies shared runtime paths and fixes reproduced correctness and
security failures. It builds on the existing uncommitted work; the Git index
was preserved. No commits, pushes, releases, or remote-machine changes were made.

## Changes

- Pool, communication, and NumPy compression imports stay independent of Torch
  and MLX. Optional public exports remain available. Hardware detection uses
  bounded, cached subprocess probes so the pool daemon does not load either
  training runtime.
- Local and distributed Torch training share batch handling. Plain tensor
  datasets now use every sample instead of interpreting rows as an input/target
  pair. Both MLX runners share array conversion and sample-count validation.
- Token persistence reuses the atomic-write utility. Failed writes preserve the
  previous credential, hardlinks are not overwritten, and reads check the
  permissions and type of the opened file rather than an earlier path lookup.
- Remote workers authorize and validate tasks before scheduling user code.
  Admission is bounded by worker capacity, including threads that continue
  after a timeout. Late failures are observed and timeout errors explain the
  possibility of continued execution.
- Multi-process tests now assert actual authenticated membership and isolation.
  New tests exercise the public Pool API through discovery, quorum, secure mesh
  formation, training, matching parameter hashes, and shutdown for both engines.
- CI covers core SDK/compute/training tests and MLX SDK/process tests that were
  previously omitted. Local audit files, test caches, and virtual environments
  are ignored by Git. Training and security documentation reflects the behavior.

Production Python changed by **205 additions and 229 removals**, a net reduction
of 24 lines. No runtime dependencies were added.

## Limits

- Separate-process tests ran on one physical Mac. Physical multi-Mac links,
  Thunderbolt/Ethernet, sleep/wake, power loss, and long-running workloads were
  not tested in this pass. The September audit is historical evidence only.
- The updated GitHub Actions matrix has not run remotely.
- A timeout cannot terminate a running Python thread. Check side effects before
  retrying. Admission limits bound queued execution, not the memory or CPU that
  trusted task implementations may consume.
- Dependency findings apply to the resolved versions tested here, not every
  older version permitted by the dependency ranges.
- The current working files were verified. Existing staged changes do not
  include all working-tree fixes and require review before committing.
