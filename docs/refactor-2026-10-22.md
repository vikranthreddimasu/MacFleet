## Additional failures fixed

- Task submission and result delivery now have bounded network writes.
  A coordinator that stops reading cannot strand submission or shutdown.
  Running Python threads retain their capacity slots until they finish.
- MLX bfloat16 gradients and parameters convert inside MLX before NumPy
  export. Checkpoints preserve bfloat16 model and optimizer state, and reject
  malformed metadata or non-finite values before mutating the model.
- Weighted batch sampling splits shared global batches so all ranks execute
  the same number of steps. The composable loop checks batch counts, epochs,
  and clipping settings across ranks and advances batch-sampler epochs.
- Handshake-specific frame limits reject oversized headers before reading
  their bodies on both client and server. Authenticated gradient transfers
  keep their existing larger frame limit.
- A single manual peer address now forms reciprocal membership between
  updated secure peers without mDNS. Reverse admission requires a fresh
  request-bound reply from the claimed identity; probes are bounded,
  coalesced, and cancelled during shutdown. Hardware metadata has shared
  type, range, and finite-value validation.
- LAN-sensitive tests use unique fleet tokens, and the fuzz generator
  distinguishes valid hardware profiles from inputs that must be rejected.
- The generated quickstart waits for two nodes when distributed mode is
  enabled, and explains stopping join daemons before running training.
- CI uses macOS 15 because GitHub is retiring the macOS 14 runner.

## Remaining limits

Tests used separate processes on one physical Apple Silicon Mac and GitHub
hosted runners. Separate physical Macs, link loss during long training,
sleep/wake, and prolonged load were not tested in this pass. Open-mode and
older peers retain their existing manual-discovery behavior. All nodes in a
secure fleet should run the same version.

Timeouts cannot kill running Python threads. A worker can take up to one task
timeout for execution plus one additional timeout to deliver a result.
The low-level gradient collective averages ranks equally; callers using
unequal local batch sizes must scale losses for sample-weighted gradients.
New bfloat16 checkpoints require the updated loader. Dependency auditing from
the preceding pass applies to the resolved versions, not every older version
allowed by package constraints.
