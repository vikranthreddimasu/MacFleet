# UI System

> Catering-ops prototype UI — not part of the macfleet pip package.

## Visual Direction

The current prototype uses a restrained monochrome palette with subtle status
accents:

- Neutral background and surfaces.
- Dark left navigation.
- Thin borders and compact spacing.
- Status accents for ready, attention, at-risk, and informational states.

## Components

- App shell
- Primary navigation
- Date/search/status filter bar
- Schedule table
- Event list table
- Event sheet header
- Event detail facts
- Sheet section
- Status badge
- Checklist row
- Intelligence panel
- Review row
- Handoff editor

## Responsiveness

- Desktop uses left navigation and two-column event detail.
- Narrow screens stack navigation and panels.
- Tables can scroll horizontally rather than hiding operational columns.

## Content Rules

- Use catering language: event, order, service, setup, delivery, production,
  checklist, review, handoff.
- Avoid autonomous-agent language.
- Keep AI copy factual and evidence-backed.
